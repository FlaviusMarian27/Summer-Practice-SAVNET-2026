# 4.1 Introduction

- source code - set de instrucțiuni citibile de omș trebuie compilat de un compiler ca să poată să devină înteleasă de calculator.
- closed source license - userii au drepturi să folosească codul mașină, dar nu pot vedea codul sursă.
- open source - userii au dreptul să obțină și să modifice codul sursă.
- linux-ul este scris in C.

## Istoric UNIX

- UNIX creat inițial în 1969.
- Organizații importante: IEEE și POSIX.

# 4.2 Open Source Licensing

1. Ownership - cine deține proprietatea intelectuală.
2. Money Transfer - cum circulă banii.
3. Licensing - ce ai nevoie să faci cu software-ul.

## 4.2.1 The Free Software Foundation

- fondat în 1985, după GNU.
- FSF - userii trebuie să aibă control asupra tehnologiei folosite.
- copyleft - dacă cineva modifică software liber, trebuie distribuit și modificat sub aceeași licență liberă.
- FSF - GPLv2, GPLv3, LGPLv2, LGPLv3.

## 4.2.2 The Open Source Initiative (OSI)

- fondată în 1998
- OSI nu are propriul set de licențe
- BSD - exemplu de licență open source mai simplă decât GPL.
- FOSS - termen colectiv pentru Free + Open Source
- FLOSS - Free/Libre/Open Source Software.


## 4.2.3 Creative Commons

- CC = pentru conținut non-software.
- Public domain - autorul o renunțat la toate drepturile.
- 4 condiții de bază:
	- Attribution (BY) - trebuie dat credit autorului.
	- ShareAlike (SA) - modificarii sub aceeași licență.
	- NonCommercial (NC) - doar uz non-comercial
	- NoDerivatives (ND) - doar copii originale, fără modificări.

- Cele 6 licențe:
	- CC BY
	- CC BY-SA
	- CC BY-ND
	- CC BY-NC
	- CC BY-NC-SA
	- CC BY-NC-ND
