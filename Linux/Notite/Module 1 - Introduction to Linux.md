
# 1.1 Linux is Everywhere

- linux-ul este peste tot.
- linux-ul folosește la bază tehnologii și metode moștenite din UNIX.
- rata de schimbare anuală este foarte mică.

# 1.2 Linux is a Kernel

### Diferența dintre kernel și GNU/Linux:

- ***Linux (Strict):*** doar kernelul, adică controlerul central al tot ce se întâmplă pe calculator.
- ***GNU/Linux:*** combinația dintre kernel + GNU -> software-ul liber care oferă echivalentul open source pentru multe comenzi UNIX obișnuite.

### Istoric scurt:

- UNIX - dezvoltat de AT&T Bell Labs în 1970 în limbajul C.
- UNIX este deținut de către Open Group.
- **Linux Torvalds** - a început Linux în 1991 ca proiect de hobby.
- Important!!! - Linux-ul nu este UNIX, este "UNIX-like".

# 1.3 Linux is Open Source

- ***Software closed-source*** = ai dreptul să folosești codul mașină, dar nu poți vedea codul sursă.
- ***Open source*** = ai dreptul să iei codul sursă și să îl modifici pentru uz propriu.
- Linux este scris în C.
- ***Proprietary*** = cod închis, controlat de o companie.

# 1.4 Linux Has Distributions

- O distribuție = kernel + tool-uri + aplicațiii.
- Principalii: Red Hat, Debian și Slackware.
- diferențele se vă la package manager.

# 1.5 Linux Embraces the CLI

- două tipuri de interfețe: 
	- GUI - Graphical user interface
	- CLI - command line interface
- CLI - ul este ideal pentru viteza și abilitatea sa de a realiza o gamă largă de task-uri printr-o singură instrucțiune de linie de comandă.
